# FoxSecura AntiVirus

Application mobile de sécurité Android et iOS développée avec Flutter.

La version initiale est un **audit de posture de sécurité et un inspecteur heuristique d'URL**. Ce n'est pas encore un moteur antivirus ni une protection en temps réel.

Le code source, les instructions de démarrage et les limitations techniques seront ajoutés dans la branche de développement.
